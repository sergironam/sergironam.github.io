# Portfolio de ciberseguridad — sergironam.github.io

Web hecha con [Hugo](https://gohugo.io) y el tema PaperMod. Se publica sola en GitHub Pages con cada `git push`.

## Crear un proyecto nuevo
```bash
hugo new content proyectos/nombre-del-proyecto/index.md
```
Las capturas van en la misma carpeta que el `index.md`. Cuando lo termines, cambia `draft: true` por `draft: false`.

## Ver la web en local
```bash
hugo server -D   # http://localhost:1313 (con -D se ven también los borradores)
```
